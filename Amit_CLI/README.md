# Amit AI | Minimal Gemini CLI

This is a clean, minimal version of Amit AI, optimized for a CLI-only experience.

## Project Structure
- `amit.py`: Main entry point (CLI).
- `amit_core/`: Contains the research logic.
- `amit_launch.bat`: Convenient launcher.
- `.env`: API configuration.
- `requirements.txt`: Python dependencies.

## Setup
1. Ensure the `knowledge_base` folder exists in the parent directory (or move it here and update paths).
2. Run the launcher:
```cmd
amit_launch.bat
```

## Cleanup
You can now safely delete all files in the original project directory except for this `Amit_CLI` folder.
