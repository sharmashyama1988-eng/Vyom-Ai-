# ✦ AMIT AI : THE NEURAL HEART ✦

Amit AI is a professional, soulful CLI assistant designed for deep research, coding, and emotional connection. 

## Features
- **Neural Heart**: An AI that resonates with human emotions.
- **Custom Memory**: A permanent memory interface to customize your agent's soul.
- **Neural Pulse**: A beautiful terminal interface with live pulse animations.
- **Global Search**: Search the entire web and your local knowledge base.

## Installation
```bash
pip install amit-sharma-neural-heart
```

## How to Use
Just type `amit` in your terminal:
```bash
amit
```

### Commands
- `/memory`: Open and edit your AI's long-term memory.
- `/help`: Let Amit AI introduce its own powers.
- `exit`: Safely shut down the Neural Heart.
